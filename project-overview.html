🚀 API 端點

🔐

Auth 認證

prefix: /auth
方法路徑權限說明
POST /auth/login 公開 登入，成功後寫入 httpOnly JWT Cookie
POST /auth/logout 登入 登出，清除 Cookie
GET /auth/me 登入 取得目前登入使用者資料
POST /auth/forgot-password 公開 申請密碼重設，寄送重設信件（30 分鐘有效）
POST /auth/reset-password 公開 使用 token 設定新密碼
👥

User 員工管理

prefix: /
方法路徑權限說明
GET /users
?search= &page= &limit=		 Admin 查詢員工列表，支援姓名/帳號搜尋與分頁
POST /user Admin 新增員工帳號
GET /user/{id} Admin 查詢單一員工資料
PUT /user/{id} Admin 更新員工資料（全量更新）
DELETE /user/{id} Admin 刪除員工帳號
📝

Leave 請假管理

prefix: /leaves
方法路徑權限說明
GET /leaves
?status= &page= &limit=		 登入 查詢請假列表；admin 看全部，員工只看自己
GET /leaves/{id} 登入 查詢單筆請假紀錄（員工只能查自己）
POST /leaves 登入 新增請假申請，初始狀態為「待審核」
PUT /leaves/{id} 登入 修改請假內容；員工只能改「待審核」的自己申請
PATCH /leaves/{id}/status Admin 審核請假（通過 / 拒絕），並記錄狀態歷史
PATCH /leaves/{id}/cancel 登入 取消請假；員工可取消「待審核」或「已通過」
GET /leaves/{id}/status-logs 登入 查詢請假狀態變更歷史（員工只能查自己）
DELETE /leaves/{id} 登入 刪除請假；員工只能刪「待審核」的自己申請
